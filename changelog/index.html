Changelog

Release notes.

Compatibility changes are called out explicitly because a receipt is meant to outlive the application that created it.

0.5.3 — legacy receipts verify again

Receipts sealed by Avow 0.4.x and older now verify again in Python and TypeScript. 0.5.0 made schema required and refused every receipt without it.

  • A receipt with no schema key is accepted as the legacy form and checked under the same payload hash and Ed25519 rules.
  • New receipts still carry schema: "avow.receipt/v1".
  • A present but unknown schema is refused with avow.receipt_schema_mismatch.
  • Tests pin receipts sealed by the released avow==0.4.1 and @edgeproc/avow@0.4.1.

0.5.2 — npm rename

The npm package is now @gainratio/avow. The old @edgeproc/avow name remains installable for 0.5.1 and older but is deprecated. No code change.

0.5.1 — CLI moved to an extra

pip install avow installs the library only. The avow command needs pip install "avow[cli]". This resolves a Typer conflict with edge-proc and assay-engine.

0.5.0 — first release from this repository

0.5.0 added the avow.receipt/v1 schema and the current npm API. It also changed the wire contract; the 0.5.3 fix restores legacy receipt verification.

The authoritative changelog is CHANGELOG.md in the repository. The site summarizes releases; the repository records every commit.
